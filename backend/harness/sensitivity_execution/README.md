# E3 — Controlled execution

This package implements the controlled-execution layer for MCAD sensitivity experiments.

## Phase boundary

E3 consumes immutable experimental instances generated by E2.2. It does not regenerate or modify those instances.

The canonical evaluator is:

backend.ckg.ckg_updater.CKGGraph.evaluate_step

E3 must call the production evaluator locally. It must not reimplement SAT, Real, Ceval, phi, or weighted phi.

## Inputs

Each controlled campaign requires:

- the immutable E2.2 campaign outputs;
- execution_spec.json;
- workload_spec.json.

The workload defines ordered query-plan steps and their objective bindings.

## Isolation

Each E2 instance is executed with:

- a fresh runtime state;
- a fresh session;
- no state reuse across instances.

## Outputs

Each instance produces:

- execution_manifest.json;
- timeline.json;
- metrics.json;
- audit.json.

Each campaign produces:

- execution_spec.json;
- execution_manifest.json;
- instance_results.csv;
- campaign_metrics.json.

## Contract validation

Run:

python backend/harness/sensitivity_execution/validate_e3_contract.py

Run the contract tests with:

python -m pytest backend/harness/sensitivity_execution/tests/test_e3_contract.py -q
