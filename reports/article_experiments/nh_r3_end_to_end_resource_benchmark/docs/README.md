# MCAD-NH-R3 - End-to-End Resource Avoidance & Time-to-Analytical-Objective-Completion

This directory is the preregistered non-human R3 station.

R3-A1 freezes the deterministic backend binding and the initial measurement protocol before any measured pilot.
R3-A2 adds a semantic/novelty refinement before measurement while preserving the R3-A1 binding byte-for-byte.

No resource-saving claim is permitted from protocol generation or semantic refinement alone.
