# R3-A2 related-work positioning notes

This file records claim boundaries relevant to the R3 protocol. It is not a
complete manuscript bibliography.

Direct comparison families include:
- goal-oriented BI / KPI / RE4DW;
- contextual knowledge graphs / semantic business analytics;
- query IR / canonical representation / cross-language interoperability;
- intentional analytics / query assessment / interestingness;
- session and multi-query analytics;
- semantic query optimization;
- empty-result / non-vacuity detection;
- provenance;
- workload/admission control;
- data skipping.

MCAD's claim must be made at the level of the integrated chain:
objective constraints/supports + cumulative evidence + objective-relative
computability + immediate/deferred contribution + safe dispensability +
pre-full-backend control.

No `first`, `only`, or absolute-priority wording is authorized by R3-A2.

External reviews, including Elicit, are advisory inputs only. Their suggestions
are retained only when they improve and remain consistent with MCAD's formal
model, frozen evidence, and independently checked literature.

The manuscript selection excludes the author-specified works of Brézillon,
Bellatreche, and Nègre while retaining the scientific families through other
representative literature.
