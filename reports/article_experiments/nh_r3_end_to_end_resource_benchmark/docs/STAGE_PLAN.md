# R3 stage plan

- R3-A1: deterministic backend-binding + initial measurement-protocol freeze (completed; immutable checkpoint).
- R3-A2: semantic/novelty refinement before measurement; binding must remain byte-identical.
- R3-B: 20-session dev instrumentation pilot; no confirmatory claim.
- R3-C: validation calibration and break-even diagnostics; no effect-size tuning.
- R3-D: confirmatory test campaign on SQL Direct.
- R3-E: XMLA/eMondrian end-to-end replication.
- R3-F: freeze and handoff to NH-R4 scale/concurrency robustness.

No stage may silently rewrite NH-R1, NH-R2, or the R3-A1 binding.
